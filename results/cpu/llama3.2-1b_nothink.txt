================================

Python's garbage collection is a mechanism that automatically frees up memory occupied by objects that are no longer needed. Here's a brief overview:

**When to Collect**
------------------

Python's garbage collector runs periodically, but it's not triggered by a specific event. Instead, it's based on the following rules:

* When an object is no longer referenced by the program.
* When an object is no longer referenced by the program and is still referenced by another object.
* When an object is no longer referenced by the program and is no longer referenced by any other object.

**How it Works**
----------------

When an object is created, Python stores it in a list called the "heap". The heap is a dynamic array that grows as objects are created and deleted. When an object is no longer referenced, Python's garbage collector checks the heap to see if it's still referenced by any other objects.

If an object is still referenced by another object, the garbage collector will collect the object and free up its memory. If an object is no longer referenced by any other object, it's considered "dead" and can be collected.

**Example**
-----------

```python
import gc

# Create a list of objects
my_list = [1, 2, 3, 4, 5]

# Print the size of the list
print(len(my_list))

# Delete an object from the list
del my_list[0]

# Print the size of the list again
print(len(my_list))
```
