        [out] **Garbage Collection in Python**

Python's garbage collection is a mechanism that automatically frees up memory occupied by objects that are no longer needed or referenced. Here's a simplified overview:

1. **Object Creation**: When an object is created, Python allocates memory for it.
2. **Reference Counting**: Each object has a reference count, which is the number of variables that reference the object. When the reference count reaches 0, the object is considered garbage.
3. **Garbage Collection Cycle**: Python periodically runs a garbage collection cycle, which:
	* Iterates through all objects in memory.
	* Decrements the reference count of each object.
	* Frees memory occupied by objects with a reference count of 0.
4. **Finalization**: When an object is garbage collected, Python may call its `__del__` method (if defined) to perform any necessary cleanup.

```python
class MyClass:
    def __init__(self):
        print("Object created")

    def __del__(self):
        print("Object deleted")

obj = MyClass()
del obj
gc.collect()  # Trigger garbage collection
```
