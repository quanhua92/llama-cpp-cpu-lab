**When to Collect**
------------------

Python's garbage collector runs periodically, but it's not triggered by a specific event. Instead, it's based on the following rules:

* When an object is no longer referenced by the program.
* When an object is no longer referenced by any other object in the program.

**How it Works**
----------------

When an object is no longer referenced, Python's garbage collector checks if it's still referenced by any other object. If not, it's collected and its memory is freed.

**Example**
-----------

```python
import gc

# Create a list
my_list = [1, 2, 3]

# Print the size of the list
```
