    *   What is the core rule? In the event of a network partition, a system can only guarantee two out of the three.

    *   Therefore, you must choose between C and A when P occurs.
    *   CP (Consistency + Partition Tolerance): Prioritizes data accuracy over uptime.
    *   AP (Availability + Partition Tolerance): Prioritizes uptime over data accuracy.
    *   CA (Consistency + Availability): Only possible in non-distributed systems (single node) or if network failure is impossible (which isn't true for distributed systems).

    *   *Definition:* The CAP theorem states that a distributed data store can only provide two out of the following three guarantees:
    *   *C (Consistency):* Every read receives the most recent write or an error.
    *   *A (Availability):* Every request receives a (non-error) response, without the guarantee that it contains the most recent write.
    *   *P (Partition Tolerance):* The system continues to operate despite network failures that prevent communication between nodes.
    *   *The Trade-off:* Since network partitions (P) are inevitable in distributed systems, you must choose between **Consistency (CP)** or **Availability (AP)** when a partition occurs.
